# RGB demo examples

These six local RGB images appear together in the Gradio example picker. Click any thumbnail, then **Reconstruct**. The added photographs are ordinary RGB samples for exploring the interface; they do not include measured HSI ground truth.

| File | Subject | Source and attribution |
| --- | --- | --- |
| `ARAD_1K_0912.jpg` | Original spectral-reconstruction example | Bundled with the upstream [MST-plus-plus repository](https://github.com/caiyuanhao1998/MST-plus-plus/tree/master/predict_code/demo). |
| `astronaut.jpg` | Eileen Collins | NASA, public-domain photograph, distributed as [scikit-image `data.astronaut`](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut). |
| `cat.jpg` | Chelsea the cat | Stefan van der Walt, CC0, via [scikit-image `data.chelsea`](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.chelsea). |
| `coffee.jpg` | Coffee cup and table | Rachel Michetti / Pikolo Espresso Bar, CC0, via [scikit-image `data.coffee`](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.coffee). |
| `rocket.jpg` | Falcon 9 / DSCOVR launch | SpaceX, public-domain photograph, via [scikit-image `data.rocket`](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.rocket). |
| `galaxies.jpg` | Hubble eXtreme Deep Field | NASA, public-domain photograph, via [scikit-image `data.hubble_deep_field`](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.hubble_deep_field). |

The five added samples were converted to RGB JPEG at their original pixel dimensions, with quality 95. The files are bundled locally; scikit-image is not needed to launch the demo.
